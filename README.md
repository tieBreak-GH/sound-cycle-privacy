# Sound Cycle

Sound Cycle is a lightweight Windows app that switches your sound output between speakers, headphones and other devices with a keyboard shortcut.

- **Privacy policy:** https://tiebreak-gh.github.io/sound-cycle-privacy/ (English and Türkçe)
- **Questions, feedback or privacy concerns:** [open an issue](https://github.com/tieBreak-GH/sound-cycle-privacy/issues)
